# 📄 AI Resume Analyzer

A Python-based Resume Analyzer that helps job seekers compare their resumes with job descriptions and understand how well their skills match a job role.

## 🚀 Features

- Upload resumes in PDF format.
- Extract text from PDF resumes.
- Detect technical skills from resumes.
- Identify required skills from job descriptions.
- Calculate the resume match percentage.
- Display matching and missing skills.

## 🛠️ Technologies Used

- Python
- Streamlit
- PyPDF
- Pandas

## 💻 Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/theburhanuddin/AI-Resume-Analyzer.git
```

**2. Open the project folder**

```bash
cd AI-Resume-Analyzer
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run app.py
```

## 📊 How It Works

1. Enter your name.
2. Paste the job description.
3. Upload your resume in PDF format.
4. Click on Analyze Resume.
5. View your matching skills, missing skills, and match percentage.

## 🎯 Project Goal

The goal of this project is to build a practical tool that helps job seekers understand their skill gaps and improve their resumes for specific job opportunities.
